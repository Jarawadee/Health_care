# Health Diary — My Personal Wellness Journal

เว็บแอปบันทึกสุขภาพส่วนบุคคลภาษาไทย พัฒนาด้วย Python, Streamlit, SQLite, Pandas และ Plotly

## คุณสมบัติ
- Dashboard คำนวณจากข้อมูลจริงใน SQLite
- บันทึกสุขภาพย้อนหลัง: การนอน เวียนศีรษะ ปวดศีรษะ และไลฟ์สไตล์
- เพิ่มอาหาร/เครื่องดื่มและยาได้หลายรายการต่อวัน
- ดูประวัติรายวันและลบข้อมูลทั้งวันพร้อมยืนยัน
- กราฟแนวโน้มอาการ การนอน และความสัมพันธ์เบื้องต้น
- ส่งออก JSON และ CSV และนำเข้า JSON
- Unit tests สำหรับฟังก์ชันหลัก

## สิ่งที่ต้องมี
Python 3.10–3.12 แนะนำ Python 3.11

## ติดตั้งและเปิดใช้งาน
```bash
# Windows PowerShell
py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1

# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate

python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```
เปิด URL ที่ Streamlit แสดงใน Terminal (โดยทั่วไป http://localhost:8501)

## ตำแหน่งข้อมูล
ฐานข้อมูลหลักสร้างอัตโนมัติที่ `data/health_diary.db` เมื่อเริ่มแอปครั้งแรก ข้อมูลยังอยู่หลังปิดแอปและเปิดใหม่ ห้ามลบไฟล์นี้หากต้องการเก็บประวัติ

`sample_data/` แยกไว้สำหรับไฟล์ตัวอย่าง ไม่มีการนำข้อมูลตัวอย่างเข้า DB อัตโนมัติ

## สำรอง / ส่งออก
- ใช้หน้า “ส่งออก / นำเข้าข้อมูล” เพื่อดาวน์โหลด JSON (ข้อมูลแบบเต็ม) หรือ CSV (สรุปรายวัน)
- สำรองฐานข้อมูลได้โดยปิดแอปแล้วคัดลอก `data/health_diary.db` ไปเก็บในที่ปลอดภัย
- JSON เหมาะสำหรับนำกลับเข้าระบบ ส่วน CSV เหมาะกับการวิเคราะห์ต่อ

## นำเข้าข้อมูล
เลือกไฟล์ JSON ที่ส่งออกจากแอปนี้ในหน้า “ส่งออก / นำเข้าข้อมูล” ตรวจสอบข้อมูลก่อนนำเข้า และสำรอง DB ก่อนเสมอ ปัจจุบันการนำเข้า JSON เป็นแบบ merge/upsert สำหรับข้อมูลหลักรายวัน และป้องกันการเพิ่มรายการอาหาร/ยาเมื่อวันนั้นมีรายการอยู่แล้ว ไม่รองรับการนำเข้า CSV

## ความเป็นส่วนตัวและข้อจำกัด
ข้อมูลอยู่ใน SQLite ภายในเครื่องและไม่มีการส่งไป API ภายนอกโดยแอปนี้ อย่างไรก็ตามฐานข้อมูลยังไม่ได้เข้ารหัส ผู้ที่เข้าถึงไฟล์ในเครื่องได้อาจอ่านข้อมูลได้ จึงควรใช้บัญชีผู้ใช้ของระบบปฏิบัติการที่ปลอดภัยและสำรองข้อมูลอย่างระมัดระวัง

หากเปิดให้ใช้งานผ่านเครือข่ายหรืออินเทอร์เน็ต ต้องเพิ่ม authentication, authorization, HTTPS, session protection, backup policy และการประเมินความปลอดภัยก่อน ไม่ควร deploy เวอร์ชันนี้เป็นบริการสาธารณะเพื่อเก็บข้อมูลสุขภาพโดยตรง

แอปนี้ใช้บันทึกและติดตามข้อมูลส่วนบุคคล ไม่ใช่เครื่องมือวินิจฉัยโรค กราฟแสดงรูปแบบที่เกิดร่วมกัน ไม่ได้พิสูจน์เหตุและผล และไม่ควรใช้ตัดสินใจปรับยา หากมีอาการรุนแรง ฉับพลัน หรือผิดปกติที่น่ากังวล ควรปรึกษาบุคลากรทางการแพทย์
