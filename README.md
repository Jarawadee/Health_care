# Health Diary — Personal Wellness Dashboard

แอป Streamlit สำหรับบันทึกข้อมูลสุขภาพส่วนบุคคลและสังเกตแนวโน้ม ไม่ใช่ระบบวินิจฉัยโรค

## ต้องมี
- Python 3.11 ขึ้นไป
- Windows, macOS หรือ Linux

## ติดตั้งบน Windows
เปิด Command Prompt หรือ PowerShell ในโฟลเดอร์โปรเจกต์ แล้วรัน:

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

เปิด URL ที่ Streamlit แสดงในเทอร์มินัล (โดยทั่วไปคือ `http://localhost:8501`)

หยุดแอปด้วย `Ctrl+C` ในหน้าต่างเทอร์มินัล แล้วรัน `streamlit run app.py` อีกครั้งเพื่อเปิดใหม่ ข้อมูลที่บันทึกแล้วจะยังอยู่ใน `data/health_diary.sqlite3`

## macOS / Linux
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## โครงสร้างฐานข้อมูล
- `daily`: ข้อมูลรายวัน เช่น การนอน น้ำดื่ม ความเครียด และกิจกรรม (หนึ่งแถวต่อวัน)
- `meals`: อาหารและเครื่องดื่ม หลายรายการต่อวัน
- `symptoms`: episode อาการ หลายรายการต่อวัน
- `medications`: รายการยา หลายรายการต่อวัน

ใช้ SQLite เก็บข้อมูลถาวรในเครื่อง ไม่มีการส่งข้อมูลสุขภาพไปยัง AI API หรือบริการวิเคราะห์ภายนอกโดยแอปนี้

## สำรองข้อมูลและส่งออก
1. หยุดแอปด้วย `Ctrl+C`
2. คัดลอก `data/health_diary.sqlite3` ไปยังโฟลเดอร์สำรองที่ปลอดภัย
3. หรือไปที่เมนู “ส่งออกและตั้งค่า” เพื่อดาวน์โหลด CSV ของแต่ละตาราง หรือไฟล์ Excel รวม

อย่าแชร์ไฟล์ฐานข้อมูลหรือไฟล์ส่งออกโดยไม่ตรวจสอบ เพราะอาจมีข้อมูลสุขภาพส่วนตัว

## ชุดข้อมูลตัวอย่าง
ไฟล์ `sample_data/` มี CSV ตัวอย่างที่เป็นข้อมูลสมมติอย่างชัดเจน สามารถนำเข้าผ่านหน้า “ส่งออกและตั้งค่า” ได้

## ทดสอบ
ติดตั้ง dependencies แล้วรัน:
```bash
pytest -q
```

## ข้อจำกัดที่ทราบ
- ข้อมูลเป็นสิ่งที่ผู้ใช้บันทึกเอง ผลลัพธ์ขึ้นกับความครบถ้วนและความถูกต้องของข้อมูล
- กราฟแสดงรูปแบบร่วม ไม่ได้ยืนยันเหตุและผลหรือวินิจฉัยโรค
- ข้อมูลรายวันเก็บหนึ่งแถวต่อวัน ส่วนอาหาร อาการ และยาเก็บได้หลายรายการต่อวัน
- การนำเข้า CSV เป็นแบบเพิ่มแถวและไม่เขียนทับฐานข้อมูลทั้งชุด แถวที่ไม่ผ่านจะถูกรายงาน
- การแก้ไขรายการผ่านหน้าเว็บเป็นช่องข้อความทั่วไป ควรตรวจสอบรูปแบบวันที่ เวลา และคะแนนหลังแก้ไข
- SQLite ไม่ได้ทำให้ข้อมูลปลอดภัยโดยอัตโนมัติ ผู้ใช้ต้องปกป้องบัญชีผู้ใช้ อุปกรณ์ และไฟล์สำรองเอง
- หากนำแอปไปเปิดออนไลน์ ต้องเพิ่มการยืนยันตัวตน การควบคุมสิทธิ์ HTTPS และการจัดเก็บที่ปลอดภัยก่อนใช้ข้อมูลจริง

## ข้อควรระวังทางการแพทย์
แอปนี้ใช้บันทึกข้อมูลและสังเกตแนวโน้ม ไม่สามารถวินิจฉัยโรคหรือระบุสาเหตุของอาการได้ หากมีอาการเวียนศีรษะร่วมกับปวดศีรษะรุนแรงฉับพลัน พูดลำบาก อ่อนแรงหรือชา เห็นภาพซ้อน หรือเดินไม่ได้ ให้รับการประเมินทางการแพทย์ฉุกเฉิน
